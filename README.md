# Responsive Webpage

A fully responsive static webpage built with pure HTML5 and CSS3.

## Live Demo

🔗 [View Live Demo](https://abraralis.github.io/Simplotel_Assignment/)

## Features

- **Responsive Design**: Adapts seamlessly to desktop, tablet, and mobile devices
- **CSS Grid Layout**: Modern grid-based layout system
- **Card-Style Images**: Images displayed in card format with shadows and rounded corners
- **No Dependencies**: Built with vanilla HTML and CSS only

## Structure

```
├── index.html      # Main HTML file
├── style.css       # Stylesheet
└── README.md       # Documentation
```

## Layout

### Desktop View
- Horizontal 3-column layout (Image | Image | Content Card)
- Full-width navigation bar with highlighted menu items

### Mobile View
- Vertical stacked navigation menu
- Images displayed side-by-side horizontally
- Content card spans full width below images

## Technologies

- HTML5
- CSS3 (Flexbox & Grid)

## Usage

Simply open `index.html` in any modern web browser.

## Browser Support

Works on all modern browsers including Chrome, Firefox, Safari, and Edge.
